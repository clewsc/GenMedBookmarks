Importing into Chrome

Takes about 30 seconds. Do this on your Citrix login, not your phone.

  1. Tick the bookmarks you want above, then choose Download bookmarks file.
  2. In Chrome, open a new tab and go to chrome://bookmarks
  3. Select the ⋮ menu at the top right of that page, then Import bookmarks.
  4. Pick the file you just downloaded. Your bookmarks appear in a folder called Imported — drag them onto the bookmarks bar wherever you want them.
  5. Can't see the bar? Press Ctrl+Shift+B.
  1. Tick the bookmarks you want above, then choose Download bookmarks file.
  2. In Edge, open a new tab and go to edge://favorites
  3. Select the ⋯ menu at the top right of that page, then Import favourites.
  4. Scroll to Import from other browsers and choose Choose what to import. Set the Import from dropdown to Favourites or bookmarks HTML file.
  5. Select Choose file, pick the file you just downloaded, then Done. Your links appear in a folder called Imported — drag them onto the favourites bar wherever you want them.
  6. Can't see the bar? Press Ctrl+Shift+B.

Coming back for more later? Importing a second time creates a new Imported folder rather than updating the first one, so you'll end up with duplicates. Either delete the old folder before you import again, or untick the links you already have.
